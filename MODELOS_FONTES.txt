BruxoSplat v1.1.0 — Fontes, ambientes e licenças
==================================================

Este documento registra a origem de cada ferramenta e modelo usado pelo app.
O código do BruxoSplat é MIT; cada dependência e peso mantém sua própria licença.

Pastas locais (%APPDATA%\BruxoSplat)
--------------------------------------
- pyenv_ppisp .............. GSplat + PPISP (ambiente isolado)
- pyenv_mast3r ............. MASt3R (ambiente isolado)
- pyenv_3dgrut ............. 3DGRUT (ambiente isolado)
- pyenv_triposplat ......... TripoSplat / TripoSR
- pyenv_faceanything ....... FaceAnything
- models_src ............... repositórios obtidos pelo app
- tools .................... ffmpeg, COLMAP, Brush e uv
- projects ................. projetos e resultados do usuário
- external_engines ......... conectores para pacotes locais não redistribuídos

Ferramentas abertas
-------------------
Brush (treino 3D Gaussian Splatting)
  Código:  https://github.com/ArthurBrussee/brush

COLMAP (reconstrução e poses)

ffmpeg (extração de frames)
  Windows: https://www.gyan.dev/ffmpeg/builds/

uv (ambientes Python isolados)
  Código:  https://github.com/astral-sh/uv

Modelos instalados pelo app
---------------------------
SHARP (foto → 3DGS)
  Código:  https://github.com/apple/ml-sharp
  Pesos:   Hugging Face, baixados na primeira execução.
  Licença: consulte o repositório e os pesos oficiais.

TripoSplat / TripoSR (imagem → asset 3D)
  Código:  https://github.com/VAST-AI-Research/TripoSR
  Pesos:   Hugging Face stabilityai/TripoSR.
  Extra:   torchmcubes, compilado em ambiente isolado.

FaceAnything (vídeo → rosto 4D)
  Código:  https://github.com/kocasariumut/FaceAnything
  Pesos:   https://huggingface.co/UmutKocasari/FaceAnything
  Licença: CC BY-NC; uso não comercial. Requer NVIDIA/CUDA.

GSplat + PPISP (treino NVIDIA)
  GSplat:  https://github.com/nerfstudio-project/gsplat
  PPISP:   https://github.com/haoyuhsu/ppisp
  Ambiente: pyenv_ppisp, separado dos demais motores.

MASt3R (alinhamento experimental)
  Código:  https://github.com/naver/mast3r
  Licença: CC BY-NC-SA 4.0 para o código/pesos oficiais; uso não comercial.

3DGRUT (ray tracing experimental)
  Código:  https://github.com/nv-tlabs/3dgrut
  Licença: consulte o repositório oficial antes de redistribuir.

MegaSam CEB portátil (câmera + profundidade)
  Base:     MegaSam e dependências fornecidas no pacote local autorizado.
  Local:    %APPDATA%\BruxoSplat\external_engines\MegaSam_CEB
  Uso:      conector experimental para cenas dinâmicas; exporta PLY/COLMAP.
  Nota:     não incluir código, pesos ou runtime CEB no repositório/release.

Backup e distribuição
---------------------
backup_modelos.bat faz uma cópia local do diretório de dados do usuário.
criar_pacote_offline.bat prepara ferramentas e ambientes abertos do app para
outro Windows compatível. Antes de compartilhar qualquer backup, remova os
pacotes em external_engines e confirme as licenças de todos os pesos.

Nunca publique em GitHub: pesos, checkpoints, modelos clonados, ferramentas
baixadas, ambientes Python, projetos, logs, resultados ou pacotes portáteis.
